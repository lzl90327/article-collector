# 用户体验优化报告 - 分阶段反馈机制

## 优化目标

提升文章收藏服务的用户体验，通过分阶段反馈机制大幅缩短用户等待时间。

---

## 优化内容

### 1. AI摘要生成时机提前

**优化前**：
- AI摘要在文档创建完成后（第8步，~51秒）才开始生成
- 用户需要等待约51秒才能看到AI摘要

**优化后**：
- AI摘要在网页抓取完成后（第4步，~5秒）立即生成
- AI摘要生成（4秒）与文档创建（42秒）**并行执行**
- 用户在约9秒后即可获得AI摘要反馈

**实施方式**：
- 将AI摘要生成提取为独立的 Promise (`aiPromise`)
- 与文档创建流程并行执行
- 完成后立即发送第一阶段卡片

### 2. 两阶段卡片反馈机制

**优化前**：
- 单一卡片在所有步骤完成后（~51秒）才发送
- 用户长时间无反馈

**优化后**：

#### 第一阶段卡片 (约9秒发送)
- 标题：⚡ AI摘要生成完成
- 内容：
  - 文章标题、作者、来源
  - AI摘要（30-50字）
  - 智能标签（2-4个）
  - 内容分类
- 说明：📝 正在后台创建飞书文档，完成后将发送文档链接...

#### 第二阶段卡片 (约51秒发送)
- 标题：✅ 文档创建成功
- 内容：
  - 文章标题、作者、来源
  - 操作按钮：查看文档、知识库、原文
- 说明：💡 深度分析正在后台进行中，完成后将自动更新多维表格...

## 技术实现

### 修改文件
- `src/handlers/message.ts` - 主要优化逻辑

### 新增函数
1. `sendQuickSummaryCard()` - 第一阶段AI摘要卡片
2. `sendDocumentSuccessCard()` - 第二阶段文档成功卡片

### 核心代码改动
```typescript
// 优化后：AI摘要与文档创建并行
const aiPromise = (async () => {
  // 生成AI摘要
  [quickSummary, tags, category] = await Promise.all([...]);
  
  // 立即发送第一阶段卡片
  await sendQuickSummaryCard(messageId, {...});
})();

// 文档创建与AI摘要并行执行
const docResult = await createDocumentWithImages(...);

// 等待AI完成
```
