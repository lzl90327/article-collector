### 3. Apple Podcasts（播客平台）⚠️

**测试播客**: [蒋奇明&双雪涛×罗永浩！如何成为飞行家](https://podcasts.apple.com/cn/podcast/id1834069371?i=1000747967318)

#### 测试结果
- ✅ **信息提取**: 85% - 标题、播客名、主播、时长、封面（简介略短，主播有小瑕疵）
- ❌ **音频下载**: 0% - 无法提取音频链接（需 Apple Music 订阅或 DRM 限制）
- ❌ **转录**: N/A - 依赖音频下载
- N/A **关键帧**: 音频内容无需关键帧
- ✅ **知识库**: 成功保存到飞书文档和多维表格

#### 技术亮点
- ✅ **HTML 实体解码**: `&amp;` → `&` 完美处理
- ✅ **时长智能解析**: 154分51秒（2小时35分）准确提取
- ✅ **多源提取**: JSON-LD + og:meta + 文本解析
- ✅ **短链展开**: 自动处理重定向

#### 平台限制分析
```
错误信息: 无法从网页中提取音频链接，可能需要 Apple Music 订阅
原因: Apple Podcasts 音频受 DRM 保护，无直接下载链接
对比: 与小宇宙的 402 错误类似，都是平台内容保护机制
```

#### 提取的信息
```json
{
  "title": "蒋奇明&双雪涛×罗永浩！如何成为飞行家",
  "podcastName": "罗永浩的十字路口",

  "duration": 9291,
  "publishDate": "2026-02-04",
  "thumbnail": "https://is1-ssl.mzstatic.com/...",
  "episodeId": "1000747967318",
  "podcastId": "1834069371"
}
```

#### 评价
⚠️ **信息提取良好（85%），但音频下载受 DRM 限制。适合作为播客索引和元数据管理。**

## 🎯 使用场景推荐

### Bilibili - 首选全功能平台 ⭐⭐⭐⭐⭐

**最佳用于**:
- ✅ 完整的视频内容分析
- ✅ 音频转录和字幕生成
- ✅ 视频关键帧提取
- ✅ 存入知识库作为学习资料

**使用示例**:
```typescript
// 完整流程
const result = await fetchBilibiliVideo(url);
const transcript = await asrService.transcribe(result.audioPath);
const keyframes = await extractKeyframes(result.videoPath);
await saveToFeishu({ ...result, transcript, keyframes });
```

---

### 小宇宙 - 播客索引平台 ⭐⭐

**最佳用于**:
- ✅ 播客元信息提取
- ✅ 播客目录和推荐
- ❌ 不支持音频下载（平台限制）

**使用示例**:
```typescript
// 仅提取信息
const result = await fetchXiaoyuzhouPodcast(url, { downloadAudio: false });
await saveToFeishu({
  ...result.info,
  note: '音频请在小宇宙 App 收听'
});
```

---

### Apple Podcasts - 播客索引平台 ⭐⭐

**最佳用于**:
- ✅ 国际播客元信息提取
- ✅ 高质量播客目录管理
- ❌ 不支持音频下载（DRM 限制）
- ✅ 知识库存储和索引

**使用示例**:
```typescript
// 仅提取信息
const result = await fetchApplePodcast(url, { downloadAudio: false });
await saveToFeishu({
  ...result.info,
  note: '音频下载受限，建议在 Apple Podcasts 收听或查找 RSS Feed'
});
```

**替代方案**:
1. 查找同一播客的 RSS Feed（可能包含音频直接链接）
2. 在其他平台（小宇宙、喜马拉雅）搜索同名播客
3. 手动下载后上传转录
