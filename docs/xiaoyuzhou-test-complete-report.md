## 🔧 修复技术详情

### 1. 时长解析修复

**问题原因**: JSON-LD 中的 duration 字段可能包含异常值

**修复方案**:
```typescript
// 添加时长验证
if (duration > 36000) { // 10小时
  logger.warn(`时长异常: ${duration}秒, 尝试从网页文本提取`);
  duration = 0; // 重置，让 fallback 处理
}

// 添加 fallback：从网页文本提取 "XX分钟"
const minutesMatch = html.match(/(\d+)\s*分钟/);
if (minutesMatch) {
  duration = parseInt(minutesMatch[1], 10) * 60;
}
```

### 2. 主播信息提取优化

**问题原因**: JSON-LD 中可能缺少 author/creator 字段

**修复方案**:
```typescript
// 添加多种匹配模式
const hostPatterns = [
  /(?:主播|主持人|嘉宾)[：:]\s*([^<\n,，]+)/i,
  /(?:导游|主持)[：:]\s*([^<\n,，]+)/i,
  /<meta[^>]*name=["']author["'][^>]*content=["']([^"']+)["']/i,
];

for (const pattern of hostPatterns) {
  const hostMatch = html.match(pattern);
  if (hostMatch && hostMatch[1]) {
    host = hostMatch[1].trim();
    break;
  }
}
```
