### 3.1 测试结果


### 3.2 问题分析

**根本原因**: Apple Podcasts 的音频内容受 DRM 保护，需要：
- Apple Music 订阅
- 或使用 Apple 官方 API
- 或通过 RSS Feed（如果播客提供公开源）

**对比其他平台**:
- **Bilibili**: ✅ 可直接下载（通过 yt-dlp）
- **小宇宙**: ❌ 402 Payment Required（付费限制）
- **Apple Podcasts**: ❌ 无直接音频链接（订阅/DRM 限制）

### 3.3 潜在解决方案

1. **RSS Feed 方式**:
   - 许多播客提供公开 RSS 源
   - 可尝试通过 Podcast ID 查找 RSS Feed URL
   - RSS Feed 中通常包含音频文件的直接下载链接

2. **API 方式**:
   - 使用 Apple Podcasts API（需要开发者账号）
   - 成本较高，适合大规模应用

3. **替代平台**:
   - 同一播客可能在小宇宙、喜马拉雅等平台有分发
   - 优先尝试其他平台

4. **手动补充**:
   - 对于重要内容，可手动下载后上传转录
