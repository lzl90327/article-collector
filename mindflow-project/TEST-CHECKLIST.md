## ✅ 完整测试流程

### 1. 首页测试
- [ ] 页面标题显示 "MindFlow 写作"
- [ ] 输入框显示默认提示文字
- [ ] "开始写作" 按钮显示正常

### 2. 创建工作流
- [ ] 输入主题："AI焦虑的本质与应对"
- [ ] 点击"开始写作"
- [ ] 显示加载动画（非白屏）
- [ ] 成功跳转到 Brief 页面

### 3. Brief 页面测试
- [ ] 显示 "写作 Brief (可微调)" 标题
- [ ] 四个 section 正常显示：
  - [ ] 核心主张 (Thesis)
  - [ ] 目标读者

- [ ] 每个 section 显示"点击编辑"按钮
- [ ] 点击编辑按钮弹出编辑对话框
- [ ] 编辑对话框包含：
  - [ ] 标题
  - [ ] Textarea 输入框
  - [ ] 取消按钮
  - [ ] 保存按钮
- [ ] 编辑内容后点击保存，内容更新
- [ ] "确认并生成切入点" 按钮正常

### 4. 角度选择页面
- [ ] 显示 "选择切入点" 标题
- [ ] 显示多个角度卡片
- [ ] 每个卡片显示：
  - [ ] 角度标题
  - [ ] 角度描述
  - [ ] 标签（主流/非主流）
- [ ] 点击卡片可以选中/取消
- [ ] 选中后显示勾选标记
- [ ] 补充想法输入框正常
- [ ] "确认选择" 按钮正常

### 5. 聊天界面测试
- [ ] 顶部显示选中的角度
- [ ] 历史消息正常显示
- [ ] 用户消息显示在右侧（蓝色气泡）

- [ ] 消息内容右侧有边距（不贴边）
- [ ] 长消息自动折叠，显示"点击展开更多"
- [ ] 点击展开后显示完整内容
- [ ] 输入框正常显示
- [ ] "发送" 按钮正常
- [ ] 可以正常发送消息
- [ ] AI 回复正常显示

### 6. 初稿页面测试

- [ ] 文章内容正常显示
- [ ] 内容右侧有边距（不贴边）
- [ ] 可以正常滚动查看
- [ ] "返回修改" 按钮正常
- [ ] "确认并审计" 按钮正常

### 7. 审计报告页面
- [ ] 显示 "审计报告" 标题
