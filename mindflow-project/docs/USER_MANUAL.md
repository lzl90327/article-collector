## 快速开始

### 1. 启动写作

在输入框中直接输入你的想法，MindFlow 会自动检测你的写作模式：

**论证模式触发词：**
- "我认为..."
- "本质是..."
- "问题在于..."
- "应该/不应该..."
- "论证..."

**观察模式触发词：**
- "今天..."
- "刚刚..."
- "在路上..."
- "记录一下..."
- "随便写写..."

### 2. 模式切换

如果你想切换模式，可以说：
- "切换到论证模式"
- "切换到观察模式"
- "我想写日记/随想"

## 双核模式详解

### 论证模式

适合：观点文章、深度分析、结构化输出

**流程：**
```
素材获取 → 选题 → 写作简报 → 切入点选择 → 观点探讨 → 观点收敛 → 草稿生成 → 审阅 → 发布 → 复盘
```

**特点：**
- 强调逻辑结构
- 多轮对话深化观点
- 严格的审阅流程
- 适合深度文章

### 观察模式

适合：日常记录、随想、不想讲道理的时候

**流程：**
```
素材获取 → 选题 → 写作简报 → 观察片段收集 → 随想整理 → 轻量审阅 → 发布 → 复盘
```

**特点：**
- 低压记录
- 不追求结构
- 快速发布
- 适合日常写作

## 完整写作流程

### Phase 0: 素材获取（可选）

**操作：**
- 输入关键词搜索素材库
- 从飞书文档导入素材
- 跳过此阶段直接开始

**提示：**
- 系统会推荐相关素材
- 可以关联多个素材
- 素材会在后续阶段自动引用

### Phase 0.5: 预选题（可选）

**操作：**
- AI 根据素材推荐 3-5 个选题方向
- 选择推荐选题或自定义
- 查看每个选题的置信度

**提示：**
- 置信度越高，选题越成熟
- 可以选择"自定义"输入自己的想法

### Phase 0.8: 自动同步（可选）

**操作：**
- 创建新的飞书文档
- 关联现有飞书文档
- 跳过同步

**提示：**
- 关联后文章会自动同步到飞书
- 可以在飞书中继续编辑

### Phase 1: 选题确认（可选）

**操作：**
- 确认最终选题方向
- 修改选题
- 重新开始选题

### Phase -1: 写作简报（核心）

**必须填写：**
1. **目标读者** - 你想写给谁看？
2. **既有信念** - 读者现在的想法是什么？
3. **改变目标** - 你想让读者改变什么？
4. **核心主张** - 一句话概括你的观点（Thesis）
5. **证据策略** - 你打算用什么支撑观点？

**操作：**
- 填写所有字段
- 查看 AI 生成的简报卡片
- 选择：确认 / 修改 / 重做

**提示：**
- 简报确认后不能随意修改
- 这是整篇文章的指南针

### Phase 1.5: 切入点选择（论证模式）

**操作：**
- AI 生成 3 个切入点候选
- 查看每个切入点的 Hook 和理由
- 选择或自定义切入点

**提示：**
- 好的开头决定读者是否继续
- 可以从痛点、故事、数据等角度切入

### Phase 2: 观点探讨（论证模式）

**操作：**
- 分享你的想法、案例
- 提出反对意见
- 要求 AI 挑战你的观点
- 输入"收敛"进入下一阶段

**提示：**
- 至少进行 3 轮对话
- 敢于提出反对意见
- 记录灵光一闪的想法

### Phase 2-C: 观察片段收集（观察模式）

**操作：**
- 随意记录观察到的内容
- 可以是场景、对话、感受
- 不需要完整，不需要结论
- 输入"整理"进入下一阶段

**提示：**
- 至少记录 3 个片段
- 像随手记笔记一样
- 系统会自动提取标签

### Phase 2-D: 随想整理（观察模式）

**操作：**
- 确定随想主题
- 基于片段撰写随想
- 确认 / 修改 / 重做

**提示：**
- 不需要完整的结构
- 可以是片段之间的联想
- 情感的自然流露

### Phase 3: 观点收敛（论证模式）

**操作：**
- 查看 AI 提取的核心要点
- 添加 / 修改 / 删除要点
- 确认要点结构

**提示：**
- 要点是文章的骨架
- 确保要点支撑核心主张

### Phase 4: 草稿生成

**操作：**
- 查看 AI 生成的草稿
- 提出修改意见
- 重新生成或修订
- 最多 3 个版本（v1/v2/v3/final）

**提示：**
- 第一版不要太追求完美
- 明确具体的修改意见
- 保留每个版本的历史

### Phase 4.3: 轻量审阅

**检查项：**
- 句子长度（过长会被标记）
- 重复词汇
- 标点符号
- 缺少问句（影响互动性）

**操作：**
- 查看问题列表
- 自动修复或手动修改
- 确认通过

### Phase 4.5: 深度审核（论证模式）

**审核维度：**
1. **Brief 对齐** - 是否符合写作简报？
2. **逻辑结构** - 论证是否清晰？
3. **论据支撑** - 证据是否充分？
4. **可读性** - 是否容易理解？
5. **伦理风险** - 是否有不当内容？

**操作：**
- 查看各维度评分
- 查看详细问题
- 修改或强制通过

### Phase 4.8: 配图生成

**操作：**
- 查看 AI 推荐的配图方案
- 生成封面图和插图
- 确认 / 重新生成 / 跳过

**提示：**
- 配图可以提升阅读体验
- 可以跳过使用自己的图

### Phase 5: 发布

**配置选项：**
- **平台**：飞书 / 微信 / 两者
- **格式**：文章 / 笔记
- **可见性**：公开 / 私密 / 受限

**操作：**
- 选择发布平台
- 预览发布效果
- 确认发布

### Phase 5.5: 观点提炼

**操作：**
- 查看从文章提炼的核心观点
- 保存到素材库
- 跳过

**提示：**
- 观点卡片可以复用
- 积累形成知识库

### Phase 6: 复盘

**回顾问题：**
1. 本次写作最顺畅的环节是什么？
2. 遇到了什么困难？如何解决的？
3. 有什么收获可以应用到下次写作？
4. 发布后数据如何？

**操作：**
- 输入复盘反思
- 查看写作数据统计
- 跳过复盘

## 操作技巧

### 快捷键

- `Ctrl/Cmd + Enter` - 提交输入
- `Esc` - 取消当前操作
- `↑/↓` - 在历史输入中切换

### 高效输入

**快速命令：**
- `confirm` - 确认当前内容
- `skip` - 跳过当前阶段
- `modify` - 修改内容
- `redo` - 重新生成
- `收敛` - 进入收敛阶段（讨论模式）
- `整理` - 进入整理阶段（观察模式）

### 中断和恢复

- 随时可以说"暂停"保存进度
- 输入"继续"恢复之前的写作
- 系统会自动保存所有内容

## 常见问题

### Q: 我想改变已经确认的 Brief 怎么办？

A: Brief 确认后有严格的修改限制。如果真的需要修改，可以在当前 Phase 输入"修改简报"，系统会评估影响并引导你完成修改。

### Q: 观察模式和论证模式可以切换吗？

A: 可以。在任意阶段输入"切换到观察模式"或"切换到论证模式"。注意：切换后部分 Phase 可能需要重新完成。

### Q: 写作过程中可以保存吗？

A: 系统会自动保存所有内容。你也可以随时输入"保存"手动触发保存。

### Q: 如何查看之前的版本？

A: 在 Drafting 阶段，输入"查看历史"可以看到所有版本。其他阶段的产物也可以在对应 Phase 查看。

### Q: 发布后还能修改吗？

A: 可以。发布后进入"已发布"状态，你可以：
- 在飞书/微信中直接修改
- 在 MindFlow 中创建修订版本
- 重新走完整的写作流程

### Q: 如何导出文章？

A: 在任意阶段输入"导出"，支持：
- Markdown 格式
- Word 文档
- PDF
- 纯文本

### Q: AI 生成的内容不满意怎么办？

A: 每个 AI 生成环节都提供：
- 重新生成（基于相同输入）
- 修改后重新生成（提供具体意见）
- 手动编辑（直接修改内容）

### Q: 可以多人协作吗？

A: 目前支持：
- 关联飞书文档后多人编辑
- 分享文章链接给他人评论
- 导出后通过其他工具协作

## 最佳实践

### 论证模式最佳实践

1. **Brief 阶段多花时间是值得的** - 清晰的简报是高质量文章的基础
2. **Discussion 阶段不要害怕被挑战** - 反驳意见让文章更有说服力
3. **Convergence 阶段确保要点支撑 Thesis** - 每个要点都要服务于核心主张
4. **Audit 阶段认真对待评分** - 低分项是提升文章质量的关键

### 观察模式最佳实践

1. **片段收集阶段不要筛选** - 先记录，后整理
2. **随想阶段不要追求完美** - 真实比完美更重要
3. **善用标签** - 方便后续检索和关联
4. **定期回顾** - 积累的观察可以形成独特的视角

### 通用建议

1. **建立写作仪式** - 固定的流程帮助进入心流
2. **积累素材库** - 好的素材是写作的弹药
3. **定期复盘** - 持续改进写作流程
4. **保持输出节奏** - 比完美更重要的是完成
